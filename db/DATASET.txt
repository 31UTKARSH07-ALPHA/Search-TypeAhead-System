Dataset source:
https://dumps.wikimedia.org/other/pageviews/

Downloaded file used for local loading:
https://dumps.wikimedia.org/other/pageviews/2026/2026-05/pageviews-20260501-000000.gz

Local path after download:
data/raw/pageviews-20260501-000000.gz

Reason for selection:
The Wikimedia Pageviews dump is an open dataset of page titles with view counts.
It satisfies the assignment requirement for at least 100,000 query-like text rows
with count/frequency values.

Load command:
npm run dataset:load

DATASET_PROJECT=en
DATASET_LIMIT=150000
DATASET_BATCH_SIZE=1000
